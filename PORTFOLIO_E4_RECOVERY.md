## Environment Variables

No runtime environment variables are required. The application is fully
client-side. Persisted state (portfolio edits + theme) lives in the browser
`localStorage` under the keys `cbk-portfolio-v3` (data) and `cbk-theme` (theme).
No `.env` file is needed; a `.env.example` is not required.

## Theme System

Two themes driven by a `.dark` class on `<html>`, toggled from the header and
persisted to `localStorage["cbk-theme"]`. All colors are CSS custom properties
defined in `src/index.css` (`:root` for light, `.dark` for dark). Crimson
accent: `#E32240` family (`--crimson`, `--crimson-rough`, `--crimson-shadow`).

## Animation Systems

All animation is CSS keyframes + `requestAnimationFrame` (no external animation
library). Key systems: name glitch, Studio Disc, ticker marquee, metric count-up,
career node cycle, radial engine, AI Lab cube, pipeline machine, fullscreen
viewer transitions. `prefers-reduced-motion` is respected throughout.

## Recovery Instructions

1. Clone / obtain this repository at the `portfolio_E4` tag (or branch).
2. `npm install` (uses the committed `package-lock.json` for exact versions).
3. `npm run build` then `npm run preview` (or `npm run dev`).
4. Verify all sections render in both light and dark themes.

## Custom Fonts (optional, licensed)

`src/index.css` declares `@font-face` slots pointing at `public/fonts/*.woff2`.
These files are licensed and intentionally NOT bundled. If absent, each font
gracefully falls back to a loaded Google Font of equivalent character (loaded
via the `<link>` in `index.html`), so the site builds and runs without them. To
activate the true faces, place the licensed files in `public/fonts/`:
`gondens.woff2`, `newspaper.woff2`, `helvetica-punk.woff2`, `r-and-c.woff2`,
`rogue-hero.woff2`, `neuhaus-headline.woff2`, `nura-semi-bold.woff2`,
`drukcond-super.woff2`.
